# Agent 学习笔记

## 一、Agent 的四个基本能力

一个可用的 Agent 通常需要具备：规划（Planning）、工具调用（Tool Use）、记忆（Memory）、执行（Action）。
本项目的重点落在其中的工具调用与记忆两块。

## 二、记忆的三层结构

- 短期记忆：最近若干轮对话原文，保证上下文连贯；
- 长期记忆：把早期对话压缩成摘要持久化，控制上下文长度与 token 成本；
- 外部记忆：向量库或笔记文件，按需检索后再放进上下文（RAG 思路）。

本项目实现了短期记忆与长期摘要两层，并用 notes/ 目录提供最简单的资料检索。

## 三、工具调用的执行流程

观察任务 → 判断是否需要工具 → 生成工具调用（名称 + 参数）→ 执行工具 → 把结果回填给模型 → 生成最终回答。
如果一轮不够，模型可以继续发起新的工具调用，直到不再需要工具为止。这个循环就是 ReAct 的核心思想。

## 四、LangGraph 与 LangChain 的分工

LangChain 负责组件与链路（Prompt、模型、解析器、工具），LangGraph 负责把流程组织成带状态、可分支、可循环的图。
流程越复杂、分支和循环越多，越适合用 LangGraph 管理；简单的单轮工具调用用 LangChain 的 bind_tools 就够。

## 五、工程化注意点

- 必须限制工具调用轮数，防止模型陷入无限循环；
- 工具执行要捕获异常并返回可读的错误信息，让模型能自我修正；
- 工具本身应无副作用或副作用可控，不要给模型执行 shell 与写文件的权限；
- 需要记录工具调用轨迹，便于排查问题与统计成本。
